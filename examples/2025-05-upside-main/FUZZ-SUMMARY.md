## 🔴 CONFIRMED finding — INV-FEE-ALWAYS (= C4 audit finding [03], swap fee bypass)

The docs-mined invariant "a buy that produces output must charge a nonzero fee" (the code states
*"Expectation is there will always be a fee >0"*) breaks: a 1-unit buy computes `fee = 1 * swapFeeBp /
10000 = 0` by integer truncation while still minting output. Medusa found it through the
Chimera-scaffolded harness; the lowered PoC (`test_repro_1` → `this.handler_buy(31)`) re-executed and
asserted harm → **CONFIRMED**. The three solvency `property_*` invariants **held**.

## Real gate improvement surfaced by running the intended flow

The Chimera harness asserts harm with Chimera's own primitives (`gt/gte/lt/lte/eq/t`), not forge's
`assertGt`/`require`. The verdict gate's `asserts_harm` didn't recognize them, so the first `verify`
returned SUSPECTED "no harm assertion". Fixed: `asserts_harm` now treats the Chimera/Recon assertion
primitives as harm (still rejecting trivial `eq(1,1)` and `handler_gt(...)` collisions). Locked in by
`tests/test_render.py::test_chimera_asserts_are_harm`.
